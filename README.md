I'm a software engineer and community builder based in Kenya. I mentor student leaders across Africa at GKSS and lead developer communities, advocating for open-source collaboration, resilient web engineering, and offline-first capabilities.

### What I work on

- Resilient web architectures & building for disconnection: offline-first Progressive Web Apps (PWAs), cache-first service worker strategies, and open web platform standards
- Speed, performance & modern web engineering: sub-second latency, zero-client bloat, streaming server rendering, and Core Web Vitals optimization
- Privacy-first systems & better web principles: local-first state persistence, permission-conscious browser APIs, and secure, respectful user experiences

### Projects

<details open>
<summary><b>Personal Projects</b></summary>
<br>

- **[SlothSort](https://github.com/bethwel3001/SlothSort):** local, privacy-first AI agent that automatically organizes cluttered folders and messy download directories into structured categories using local LLMs. Next.js 19, Mastra Agent Framework, Google Gemma (Ollama), Sentry, Tailwind CSS.
- **[d3mon](https://github.com/bethwel3001/d3mon):** experimental web application ("Ghost in the Git") that surfaces abandoned GitHub repositories, interrogates dormant commit histories with open-weight LLMs, and synthesizes spoken poetic eulogies. Next.js, Node.js, ElevenLabs, GitHub API.
- **[ssui](https://github.com/bethwel3001/ssui):** real-time event Q&A and live audience polling platform for developer meetups and conferences featuring multi-room workspaces, instant gating, and live voting. Angular, AWS Serverless, TypeScript, WebSockets.
